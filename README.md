# family-tree-research
Навык помогает искать в различных архивах предков по данной вами информации. Лучше указывать ФИО, дату и место рождения предка или ФИО, дату и место свадьбы. Далее ИИ будет искать предудщие поколения по вашим данным. В случае с переездами будет тяжело. Советую внимательно следить за размышлениями ИИ, он может ошибаться и путать рукописный текст. Найденных кандидатов проверяйте сами, добавляйте кандидата в родословную, если у него совпадают несколько фактов, например имя детей, год рождения и место жительства.
