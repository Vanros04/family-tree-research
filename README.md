# family-tree-research
Навык помогает искать в различных архивах предков по данной вами информации. Лучше указывать ФИО, дату и место рождения предка или ФИО, дату и место свадьбы. Далее ИИ будет искать предудщие поколения по вашим данным. В случае с переездами будет тяжело. Советую внимательно следить за размышлениями ИИ, он может ошибаться и путать рукописный текст.
