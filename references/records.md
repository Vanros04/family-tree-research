# Файлы и шаблоны

## Организация

Использовать существующие файлы и идентичности, не создавать новые дубликаты на каждое «продолжай». Сохранять пользовательские материалы средствами долговременного хранения, доступными в среде. Не обещать сохранность временной папки. Меняющиеся семейные сведения хранить отдельно от навыка.

1. **Текущее состояние.md**, ориентир 1–2 страницы: дата/итерация; ссылки и версии файлов; карта веток; активный вопрос; краткие карточки ключевых людей с ID; сильные кандидаты; противоречия; последнее выполненное действие; очередь; точка продолжения. Подробности переносить в журнал с ссылками.
2. **Рабочий журнал.md**: индекс веток/людей/источников; карточки людей и связей; выписки; гипотезы/исправления; хронологический журнал проверок. При росте выносить ветки в отдельные файлы с индексом; читать только нужные. Использовать постоянные ID и заголовки.
3. **Семейные факты.pdf**: понятный родственникам рассказ, достаточно надёжные факты, документы с подписями и источниками. Различать документальное подтверждение, высокую вероятность и семейный рассказ. Слабых кандидатов не включать как предков. При отсутствии новых фактов оставлять прежнюю версию.
4. **Приложения**: оригиналы, фрагменты, расшифровки, таблица источников и технические проверки. ZIP создавать при пользе для переноса или запросе. Исключать пароли, токены, данные входа и временные подписанные ссылки.

**Рабочий PDF** — переносимая версия журнала и доказательств. Держать актуальное состояние в начале, затем карточки, источники и хронологию. Не наращивать повторяющиеся вступления. При реорганизации сохранить существенные доказательства, отрицательные проверки, объяснения исправлений и доступ к прежнему PDF. Не заниматься масштабной перестройкой вместо поиска без запроса.

## Сохранение

- Промежуточно сохранять законченный раздел, проверку кандидата, препятствие; ценную находку — сразу.
- После каждой итерации обновлять состояние и MD.
- Рабочий PDF обновлять после существенных результатов, перед переносом или по запросу. Иная явная частота пользователя имеет приоритет.
- Семейный PDF обновлять при новых достаточно надёжных фактах; сообщать, если не менялся.

Не называть черновик полностью обновлённым единым отчётом. При сбое указать сохранённое и ещё не включённое. Для PDF применять доступный профильный навык: проверить кириллицу, таблицы, ссылки и читаемость документов. Если создание PDF невозможно, сохранить полноценный текст и сообщить ограничение.

## Карточка человека

```text
ID; имя и варианты:
Статус тождества и основания:
Рождение: точная дата / диапазон / источник / календарь:
Места: проживание / событие / регистрация / гипотеза происхождения:
Родители, супруги, дети: отдельный статус и источники каждого звена:
Сословие, занятие, окружение:
Противоречия, сомнительные чтения:
Кандидат: совпадения / различия / недостающая связка:
Следующая проверка:
```

Для связи сохранять отдельную строку: A — тип родства — B — документы — статус — вопросы. Дерево не заменяет доказательную цепочку.

При росте объёма использовать `registers.md`: постоянные ID людей, источников, утверждений и связей. Добавлять к существующей работе постепенно; полную миграцию без необходимости не выполнять.

## Карточка источника

```text
ID; человек и устанавливаемый факт:
Класс: рассказ / публикация / опись-карточка / оригинал-копия / гипотеза:
Архив, фонд, опись, дело:
Год, приход/учреждение, раздел, номер записи:
Лист и оборот (или «не установлен»):
Внутренняя страница:
Цифровое изображение и страница PDF отдельно:
Микрофильм / item / DGS:
Постоянная прямая ссылка; дата обращения:
Сохранённый скан/фрагмент, если есть:
Существенная расшифровка с [?]; нормализация отдельно:
Что подтверждает / чего не доказывает:
Группа происхождения/зависимости копий (independence_group):
Связанные карточки; следующий способ проверки:
```

Отсутствующие реквизиты и ссылки не придумывать. Если есть только карточка — написать это. Для рассказа указать рассказчика и дату при наличии; для публикации — автора, страницу и исходный документ.

## Журнал просмотров

Таблица/CSV: `iteration,date,question,source_id,case,parish,section,years,image_start,image_end,gaps,leaves,method,result,last_read,next_action`.

Метод: оригинал визуально / индекс / OCR / каталог / только скачано. Несмежные интервалы писать отдельно либо явным списком. Повтор снабжать причиной. Отрицательный результат ограничивать методом и диапазоном; различать отсутствие фамилии, раздела и доступа. Непросмотренные скачанные файлы не включать в отрицательный просмотр.

## Исправления и дерево

Указать прежний вывод, новый статус, дату и причину; не затирать ошибку бесследно и не пересказывать её в каждом ответе. Изменения дерева перечислять отдельно: добавить/уточнить/разъединить, основание, статус. Кандидатов не превращать в подтверждённых предков. Отсутствие изменений также фиксировать.

## Точка продолжения

Человек; вопрос; точное дело/источник; проверенные диапазоны и пропуски; последнее действительно прочитанное изображение; следующее действие; резерв при блокировке. Если просмотр не начат — так и написать.

В чат вынести только изменения: находки, новые выводы из прежних документов, гипотезы, отрицательные диапазоны, неопределённости и следующий шаг. Дать ссылки на сохранённые файлы. Для переноса подготовить компактный стартовый запрос и минимальный набор приложений; не требовать полного перечитывания сотен страниц при каждом продолжении.
