# Реестры и механическая проверка

Вести обычные карточки из `records.md`. При росте числа источников и кандидатов использовать CSV для связности: не переписывать всю историю исследования и не создавать второе конкурирующее хранилище. Добавлять только текущие существенные утверждения. Шаблоны находятся в `assets/registers/`; копировать в папку конкретного исследования вне каталога навыка. Семейные данные не сохранять в самом навыке.

## Схема

- `people.csv`: `person_id,label`. Назначать отдельные ID однофамильцам до разрешения тождества. Метка не доказывает личность.
- `sources.csv`: `source_id,independence_group,locator,kind`. Один ID на конкретный артефакт. В `locator` указывать ссылку/шифр и кадр или путь. Группа означает общее происхождение сведений, а не общий сайт. Неизвестную зависимость обозначать `unknown`; не создавать фиктивные разные группы для усиления вывода.
- `claims.csv`: `claim_id,person_id,statement,source_ids,status,note`. Каждая строка — проверяемый факт. Ссылки на источники разделять `|`. В `note` фиксировать ограничения, противоречия и следующий способ проверки.
- `relationships.csv`: `relationship_id,from_person_id,to_person_id,relation,claim_ids,status,note`. Каждая строка — одна связь, её основания и сомнения. Ссылки на утверждения разделять `|`. Для статуса связи нужна содержательная оценка именно родства; подтверждённое рождение одного человека не подтверждает автоматически связь с другим.

Не менять прежние статусы молча. Для новых строк использовать:

| Статус | Смысл |
| --- | --- |
| `hypothesis` | Проверяемая версия; источников может ещё не быть |
| `single-source` | Есть одно происхождение сведений, даже если копий несколько |
| `corroborated` | Есть не менее двух проверенных независимых оснований, непосредственно поддерживающих это утверждение; противоречия рассмотрены |
| `unresolved` | Чтение, зависимость или тождество пока не решены |
| `contradicted` | Версия противоречит проверенным сведениям; сохранить причины |

Статус не равен истинности: ясный акт с одним источником может быть очень весомым; две ошибочные или нерелевантные записи не становятся доказательством из-за числа. В семейном рассказе объяснять основания обычным языком. Старое «подтверждено» сопоставлять с документами индивидуально, не перекодировать автоматически.

## Аудит

Запустить перед существенным выводом или переносом, если используются эти реестры:

```bash
python /путь/к/навыку/scripts/audit_registers.py /папка/исследования
```

Скрипт только читает CSV. Код 0 — механических ошибок не обнаружено; 1 — есть ошибки/предупреждения, требующие разбора; 2 — ошибка запуска. Отсутствующие реестры перечисляются как непроверенные; пустые шаблоны не являются проверенным исследованием. Если используется другой формат, проверить соответствие вручную, не переносить данные лишь ради скрипта.

Проверяются дубликаты ID, ссылки между реестрами, допустимые статусы и фактические группы процитированных источников. У `corroborated` менее двух известных групп — ошибка; у `single-source` без источников — ошибка. Количество групп у связи — только верхняя граница: это не автоматическая оценка того, что каждое основание действительно доказывает родство.

После аудита вручную сверить существенные выписки с изображениями и каждое звено родства с его основаниями. Не объявлять аудит проверкой почерка, правдивости исторического документа или доказанности родства. Не повышать статусы и не исправлять семейные сведения автоматически ради успешного запуска.
